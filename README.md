# monaspace-ttf

Personal repository of TTF equivalents of vanilla Monaspace font files (basic width).

I have created this repository for my personal use so that I can keep TTF versions of the original OTF files where I can easily reach them. The files are the vanilla versions of Monaspace fonts, i.e. no NerdFont patches etc. I don't care about that. The fonts have also not been tampered with in any way apart from the TTF format conversion itself.

They do, however, contain the full set of stylistic alternates that the OTF files contain. This was the primary motivation for the creation of this repository. The TTF files from upstream are "frozen" meaning they have some defaults that cannot be changed since most IDE's don't usually support set-up of stylistic alternates. However, now that the JetBrains IDE's that I use allow selection of these stylistic alternates, I wanted to have those available.

Finally, the files are in TTF format since I needed them to work in Windows where they will be installed in the user's personal profile. For whatever reason, only TTF files work that way and are actually visible from within the JB IDE's.
